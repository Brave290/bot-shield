# Contributing to BotShield

Thank you for your interest in contributing to BotShield! We believe that open-source bot protection should be transparent, community-driven, and secure.

## Getting Started
1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/bot-shield.git`
3. Install dependencies: `npm install`
4. Set up your local environment (see `.env.example`)

## Development
- Run the development server: `npm run dev`
- Run the smoke tests before submitting a PR: `npm run smoke`

## Pull Request Process
1. Ensure your code passes all CI checks (TypeScript, ESLint, Smoke Tests).
2. Update documentation if you change API behavior.
3. A maintainer will review your PR as soon as possible.

## Code of Conduct
Please be respectful and constructive. We are building a safer web together.
