# Security Policy

## Supported Versions
We actively support the latest major release of BotShield.

## Reporting a Vulnerability
We take the security of BotShield seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to: **security@botshield.dev** (or your actual email).

You should receive a response within 48 hours. If the issue is confirmed, we will release a patch as soon as possible depending on complexity.

## Preferred Languages
We prefer all communications to be in English.
